# 🎓 Scholarship Tracker Pro

> A smart scholarship tracking tool to help students discover, monitor, and manage upcoming internships, research assistant (RA) positions, and funded Masters & PhD scholarships worldwide.

[![Live Demo](https://img.shields.io/badge/Live%20Demo-rising03.github.io-blue?style=for-the-badge)](https://rising03.github.io/scholarship-tracker-pro/)
[![MIT License](https://img.shields.io/badge/License-MIT-green?style=for-the-badge)](LICENSE)

---

## ✨ Features

- 🌍 **Global Coverage** — Scholarships and opportunities from universities worldwide
- 🔔 **Deadline Tracking** — Never miss an application deadline
- 🔍 **Smart Filtering** — Filter by country, field, funding type, and degree level
- 📊 **Dashboard View** — Clean UI to manage your application progress
- 📱 **Responsive Design** — Works on all devices

## 🚀 Getting Started

### Open the live app:
👉 [https://rising03.github.io/scholarship-tracker-pro/](https://rising03.github.io/scholarship-tracker-pro/)

### Run locally:
```bash
git clone https://github.com/rakibdipu/scholarship-tracker-pro.git
cd scholarship-tracker-pro
# Open index.html in your browser
```
